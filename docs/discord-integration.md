# Discord Bridge Boundary

This repository no longer owns the Copilot/Discord bridge workflow, launcher scripts, or setup instructions.

Bridge-specific assets such as Discord bot token setup, `copilot-bridge-v2.mjs`, interactive bridge launchers, dashboard guidance, and MCP configuration belong with the standalone bridge tooling or user-level Copilot configuration, not with the meal-planner application repo.

Use repo-owned evidence for meal-planner work instead:

- GitHub Actions workflows in `.github/workflows\`
- PR preview comments and workflow logs
- Live frontend/API preview URLs and health endpoints

This file remains only as a boundary note so bridge documentation does not drift back into the product repository.
